# 枕边翻页 · Pillow Reader

用闭眼或张嘴动作操作电脑微信读书网页版的实验性浏览器扩展。当前版本：**0.1.1**。

## 功能

- 双眼闭合稍停后睁开，或张嘴稍停后合上，向后翻页。
- 默认停留约 0.65 秒，触发后间隔约 2.2 秒，超过 2.5 秒的动作取消。
- 中性表情校准、实时闭眼/张嘴数值、可调触发线。
- 短促眨眼、丢失人脸和检测帧中断的防误触处理。
- 仅在本机处理摄像头视频，不录制、不上传，不使用分析服务。

## 安装与使用

1. 下载此仓库并解压，或从 Releases 下载扩展 ZIP 并解压。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。从源码安装时选择仓库里的 `extension/`；从扩展 ZIP 安装时选择 `pillow-reader-extension/`。
4. 在 [微信读书网页版](https://weread.qq.com/) 登录，打开一本书并使用翻页模式。
5. 点击浏览器工具栏的扩展图标。在控制窗选择书籍，点「测试下一页」，确认书页确实变化。
6. 保持阅读姿势，开启摄像头，睁眼合嘴看向屏幕约 3 秒完成校准。
7. 点击「开始免手翻页」，确认状态为「正在陪读」。闭眼约 0.65 秒再睁开，或选择张嘴模式，张嘴稍停后合上。

控制窗须保持可见。进入后台或最小化会暂停；重新显示后需点击开始。切换动作模式会继续运行。空格暂停/继续，Esc 暂停；点击「关闭」释放摄像头。

若动作数值低于触发线，展开「动作识别灵敏度」调低触发线；误触较多时调高。默认闭眼触发线为 50%，张嘴为 20%。

更新已有安装时覆盖原扩展文件夹，在扩展管理页重新加载，然后关闭旧控制窗并重新打开。

## 开发与测试

需要 Node.js 和 Python 3，无需安装 npm 依赖。

```sh
npm test
npm run build
```

`build/` 生成可安装扩展 ZIP，`dist/` 生成网页试读。网页试读独立运行，不能直接控制其他网站；控制微信读书需安装扩展。

```sh
python3 -m http.server 8000
# 在浏览器打开 http://localhost:8000/dist/
```

测试控制器时可使用合成视频和合成表情结果，无需开启真实摄像头：

```sh
npm run prepare:qa
python3 -m http.server 8000
# 在浏览器打开 http://localhost:8000/.qa/
```

在合成测试页面点击测试下一页、开启摄像头并等待校准、开始免手翻页，再使用「模拟一次闭眼／张嘴」。这里的“摄像头”是测试代码生成的视频流。

13 个自动测试覆盖手势释放触发、自然眨眼过滤、帧中断、丢脸、冷却、触发线，以及翻页消息与目标检查。合成测试不代表真实视觉模型在不同人脸、卧姿和光线下的识别率。

## 当前限制

这是原型，仍需在实际设备上验证。眼镜、侧躺、弱光及摄像头角度可能影响识别。第一版只通过动作向后翻页；向前可用控制窗的测试按钮。暂不支持 iPad 微信读书 App。

翻页按钮点击已执行和书页变化已确认会分别报告。微信读书可能在不改变对应 DOM 的情况下重绘画面，因此无法自动确认时，以实际书页变化为准。试读结束、登录弹窗或网站结构调整也可能使翻页不可用。
