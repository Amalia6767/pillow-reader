# 隐私与权限

- 开启摄像头由使用者主动点击并通过浏览器授权。只请求视频，不请求音频。
- 视频帧和表情系数仅在控制窗进程中处理。代码不将它们上传、录制、写入日志或存储。
- 关闭摄像头或控制窗会停止视频轨道并释放模型。
- 模型、WASM 和识别库已随扩展打包，运行时无需向模型 CDN 请求文件。
- 不使用统计、广告或第三方分析脚本。
- 扩展仅申请 `scripting` 和 `https://weread.qq.com/*` 权限，列出匹配的阅读标签页，并在所选页面查找翻页按钮。
- 翻页确认在阅读页内部比较局部 DOM 状态，返回操作是否发送及是否检测到变化，不向控制窗或网络传输书籍正文。
- 不请求 Cookie、密码、浏览历史、麦克风或其他网站的权限。

浏览器对摄像头授权的保存，以及微信读书网站自身的网络请求，由对应浏览器和网站管理。
